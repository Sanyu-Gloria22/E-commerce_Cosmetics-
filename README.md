# SORA

A modern luxury cosmetics e-commerce website designed to provide an elegant and engaging beauty shopping experience.

## Features

* Responsive luxury-inspired design
* Skincare, makeup, haircare & fragrance categories
* Featured/best-selling products
* Product ratings and pricing
* Interactive ingredient section
* Customer testimonials carousel
* Promotional offers
* Newsletter subscription
* Mobile navigation

## Built With

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Google Fonts
* Cloudinary

## Getting Started

Clone the repository and open `index.html` in your browser, or use VS Code Live Server.

```bash
git clone https://github.com/your-username/sora.git
```
